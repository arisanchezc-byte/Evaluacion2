# Evaluación 2 - Telepresencia y Entornos Innovadores de Colaboración Humana (CUY6142)

## Descripción del Proyecto
Este proyecto corresponde a la Evaluación Parcial N° 2. Contiene el desarrollo de una solución de software en Python que consume las APIs de **Graphhopper** (Geocoding y Routing) para ofrecer a los visitantes de la Biblioteca Nacional rutas y tiempos optimizados de viaje.

## Requisitos
* Python 3.8+
* Librería `requests`:
  ```bash
  pip3 install requests

# Forma de uso:

Inicialmente, debes colocar una Clave API desde este link https://docs.graphhopper.com/openapi
luego necesitas enrolarte y prosteriormente crear una Clave API para poder ocupar el programa


Una vez conseguida la clave y colocada en el apartado correspondiente (ubicada al principio)
puedes hacer uso de la herramienta. Requieres colocar ubicaciones del planeta para poder definir
ubicación y rutas, entre más especifico seas mejor, es decir, colocar nombre de ciudades hasta 
otras. 

En caso de equivocarse en una letra, la propia herramienta detecta y selecciona la ubicación lo 
más parecida a la respuesta erronea o en caso de no averigurarla, informara que se les es imposible. 
En caso de querer terminar el programa solo necesitas seleccionar la tecla "s" o escribir la palabra 
"salir" para asi terminar su ejecución.

Sientete libre de modificarlo
